# 反应挑战 (Reaction Challenge)

> ⚠️ **18+ 成人内容警示**：本应用包含成人向指令与素材，仅限 18 周岁及以上用户使用。首次打开会显示年龄确认门（localStorage 记录，仅需确认一次）。本应用仅用于放松、注意力与反应练习及娱乐体验，不构成医疗建议、诊断或治疗。

纯前端、零依赖、零构建的本地反应/延迟挑战训练应用。双击即玩。

## 项目来源

本项目参考了 [cumwithme](https://cumwithme.edgecontrol.workers.dev/) 的反应挑战玩法，在其基础上进行了**本地化与大幅增强**，形成了纯本地运行的个人版本。

### 与参考版（cumwithme）的对比

| 能力 | 参考版 cumwithme | 本版 reaction-challenge |
|---|---|---|
| **运行方式** | 在线网站（Workers 托管） | 本地双击 `index.html`，完全离线 |
| **年龄确认** | 独立确认页（每次打开都要确认） | 年龄门遮罩，**localStorage 记住，仅首次确认** |
| **医疗免责声明** | ✅ 有 | ✅ 有（已对齐参考版） |
| **任务库** | 16 条固定任务 | 默认指令库（难度×阶段矩阵）+ **自定义指令** |
| **任务时长** | 三角分布随机（5-15 秒） | 同上 + 支持指令自定义时长（`@秒数`） |
| **奖励机制** | 文字奖励 + 10 秒倒计时 | 文字奖励 + **全屏播放激励素材**（图片/视频）+ 声音开关 + 视频进度条 |
| **激励素材** | ❌ 无 | ✅ 本地文件夹素材池（目录选择，IndexedDB 记住） |
| **媒体时长设置** | ❌ 固定 | ✅ 设置面板可调：背景图切换秒数、背景视频/奖励视频最大时长（0=不限），localStorage 持久化 |
| **视频进度条** | ❌ 无 | ✅ 训练背景与奖励视频底部均有播放进度条 |
| **自定义指令** | ❌ 无 | ✅ 难度/阶段标签、红屏指令、随机数字/随机选项 |
| **数据持久化** | ❌ 会话内，刷新即失 | ✅ localStorage 持久化（指令、年龄确认、素材记忆） |
| **屏幕控制** | 无 | Wake Lock 防息屏 + 全屏模式 |
| **素材依赖** | 无 | 需自备 `media/` 素材文件夹 |

**一句话**：参考版是「网页版原型」，本版是「增强的纯本地个人版」——离线可用、可自定义、素材可扩展、记住你的选择。

## 功能

- **独立设置页**：媒体时长、玩法设置、自定义指令、素材选择收纳到单独的「⚙️ 玩法设置」页，难度/开始页保持简洁，仅显示当前玩法摘要
- **多难度**：简单 / 普通 / 困难（不同强度与羞耻度的任务指令库）
- **多时长**：5 / 10 / 15 / 20 分钟
- **三阶段**：热身 → 推进 → 高潮边缘
- **奖励机制**：完成任务随机触发奖励挑战，全屏播放激励素材（图片/视频），可开关声音；可点「⏭ 换一个」更换不满意的素材
- **视频进度条（可拖动）**：训练背景与奖励视频底部均有红色进度条，点按/拖动可跳转播放位置（浏览器支持 seek 时）；任务卡进度条**常驻不隐藏**（奖励视频时同步显示视频播放进度）
- **训练控制**：训练中可一键暂停/继续（冻结倒计时）、右上角一键静音背景声 + 音量滑杆；训练页顶部实时显示本轮剩余时间（分:秒）
- **任务卡可拖动**：训练/奖励任务卡顶部有小横条手柄，按住可拖到屏幕任意位置（位置自动记住，双击手柄复位）
- **奖励播放速度**：奖励视频右上角速度按钮，1x→1.25x→1.5x→2x→0.75x 循环切换，持久化记忆
- **奖励视频随机起点**：玩法设置可开启；超过 30 秒的视频从随机位置开始播（在 0~80% 区间，避免每次都从头看）
- **跨轮累计统计**：结束页展示累计轮数 / 任务数 / 总用时（localStorage 持久化，与单轮统计分开两行显示）
- **奖励音量滑杆**：奖励视频右下角独立音量滑杆，与背景音量分开记忆；静音状态下拖动会自动取消静音
- **背景视频**：播完自动切下一个素材（双缓冲预加载，切换无黑屏）；背景图片切换带淡入过渡；默认有声，可在设置或右上角一键静音
- **媒体时长可配置**：设置面板可调背景图切换秒数、背景视频最大时长、奖励视频最大时长（背景视频填 0 = 不限制，播完自动切下一个素材；奖励视频填 0 = 播完即结束），localStorage 持久化
- **玩法设置**：成功概率(%)、任务随机时长范围(秒)、奖励图片时长(秒)、画面填充（完整显示/铺满裁切），localStorage 持久化
- **训练快捷键**：空格=暂停/继续（训练中）、N=换奖励素材、M=背景声音开关、←/→=视频快退/快进 10 秒、↑/↓=音量 ±10%（奖励时调奖励音量、训练时调背景音量）；输入框聚焦时不拦截
- **全屏沉浸**：训练/奖励时鼠标停止不动≈2.6s，底部按钮与进度条自动淡出（鼠标一动即回）；任务文字始终可见
- **奖励连播**：玩法设置可选 1/3/5 个素材自动连播后再结算，可随时「换一个」（不消耗名额）；换素材/连播前已预加载下一个，切换更顺
- **结束页**：支持「再来一轮」（同难度同时长直接开）或返回设置；展示本轮任务数与实际用时、跨轮累计统计（可一键清零）
- **记住上次选择**：难度与时长会自动记住，下次打开自动带出（localStorage 持久化）；玩法设置（成功概率/任务时长/画面填充等）也持久化，启动页显示「当前玩法」摘要
- **自定义指令**：支持难度/阶段标签、红屏指令、定时指令、随机数字/随机选项，localStorage 持久化
- **自定义素材**：可选择一个本地文件夹作为激励素材池（Chrome/Edge 会记住目录，IndexedDB 持久化；其他浏览器每次选择）
- **单文件版**：`python3 tools/build_single.py` 构建出 `challenge.html`（CSS/JS/素材清单全内嵌，104KB），与 `media/` 文件夹放一起双击即用；`--copy-desktop` 同时拷贝到桌面并建好素材软链
- **手机局域网访问**：电脑与手机连同一 WiFi，在项目目录运行 `python3 -m http.server 8000`，手机浏览器访问 `http://<电脑局域网IP>:8000`（IP 用 `ip addr` 查，一般为 192.168.x.x）；体验与电脑一致，素材、设置各自存在手机浏览器里
- **年龄确认门**：首次访问必须确认 18 周岁以上，含医疗免责声明

## 使用

1. 克隆或下载本仓库
2. 在项目根目录建一个 `media/` 文件夹，放入你自己的图片/视频素材（**素材不上传仓库，需自备**；重复文件建议去重，避免同一素材被拍中概率放大）
3. 双击 `index.html`（或放到任意静态服务器）
4. 首次打开确认年龄 → 选择素材文件夹 → 开始

### 素材说明

`media/` 文件夹被 `.gitignore` 排除——它存的是个人激励素材（图片/视频），体积大且属个人内容，不适合公开托管。分享本仓库只含代码，任何人拿到后放入自己的素材即可运行。

## 技术栈

纯 HTML + CSS + Vanilla JS，无框架、无构建、无依赖。所有状态用 localStorage/IndexedDB 本地存储。

## 素材去重与清单

`media/` 里如果积累了重复文件（同名不同命或多次下载），可用一行命令去重（移入回收站，可恢复）：

```bash
cd media && md5sum * | sort | awk 'seen[$1]++ {print $2}' | while IFS= read -r f; do gio trash -- "$f"; done
```

素材清单 `media/manifest.json` 在 http 服务模式下优先加载，重建：

```bash
python3 - <<'EOF'
import json, os
files = sorted(f for f in os.listdir('media') if os.path.isfile(f) and f != 'manifest.json')
json.dump(['media/' + f for f in files], open('media/manifest.json', 'w'), ensure_ascii=False, indent=1)
EOF
```
